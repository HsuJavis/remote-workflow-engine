## 4. Self-sustainability — closed-loop autonomy and lifecycle

### QD2-O2 — LOW — NEW/RESIDUAL — The three ported tabs fetch their own endpoint inside `onTick` in addition to the one `app.js` already fetched for them, so each tick on a visible ported tab is two requests to the same route and the `bodies` contract is bypassed
